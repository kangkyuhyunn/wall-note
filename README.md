# Wall Note

화면에서 원하는 위치에 놓고 쓰는 작은 macOS 메모 앱입니다. 크림색 메모 카드와 연한 민트색 할 일 카드를 사용합니다. SwiftUI와 AppKit으로 만들었으며 외부 패키지나 웹뷰가 없습니다.

## 실행

빌드한 **Wall Note 1.6.app**을 더블클릭하세요. GitHub에서 소스를 받았다면 아래 빌드 명령을 먼저 실행하세요. Apple Silicon Mac, macOS 13 이상에서 사용할 수 있습니다. 앱 파일만 응용 프로그램 폴더로 옮겨서 사용해도 됩니다.

기존 SideMemo가 실행 중이면 컨트롤 바의 **앱 종료**로 먼저 종료한 뒤 Wall Note를 여세요. 같은 저장 파일을 사용하므로 기존 메모가 이어집니다.

## 1.6 변경 사항

- 앱 이름을 **Wall Note**로 변경했습니다. 앱 파일, 메뉴, 창 이름과 접근성 안내에 새 이름을 사용합니다.
- 기존 SideMemo 메모와 카드 높이, 창 위치를 그대로 이어서 사용합니다. 호환성을 위해 내부 앱 식별자와 저장 폴더 이름은 유지합니다.
- GitHub에서 관리할 수 있도록 소스와 빌드 스크립트를 별도 프로젝트로 정리했습니다.

## 1.5 변경 사항

- 컨트롤 바 왼쪽의 **점 6개 손잡이**를 드래그하면 컨트롤 바와 메모 전체를 원하는 위치로 옮길 수 있습니다. 다른 모니터로도 드래그할 수 있습니다.
- 손을 놓으면 위치와 창 너비를 자동 저장합니다. 다시 열어도 선택한 위치에 나타나며, 메모를 추가하거나 카드 높이를 조절해도 컨트롤 바의 위치를 유지합니다.
- 아래쪽에 놓으면 남은 공간 안에서 카드 목록이 스크롤됩니다. Dock에 너무 가까우면 컨트롤 바와 짧은 카드 하나가 보일 만큼만 위로 보정합니다. 메모가 없으면 컨트롤 바만 놓을 수 있습니다.
- 손잡이를 **더블클릭**하거나 우클릭 → **오른쪽으로 되돌리기**를 선택하면 원래의 자동 오른쪽 배치로 돌아갑니다. 메뉴 막대의 메모 아이콘 우클릭 메뉴에서도 선택할 수 있습니다.
- 선택한 모니터를 해제하면 연결된 화면 안으로 옮겨 표시하고, 원래 모니터를 다시 연결하면 저장한 위치를 복원합니다. 해상도와 화면 배치가 바뀌어도 화면 안에 표시합니다.

## 1.4 변경 사항

- 카드, 스크롤 영역, 실제 창이 같은 높이 계산을 사용합니다. 손잡이를 드래그하는 동안 창도 함께 늘어나며, 기존 목록의 측정 높이에 막혀 카드 하단이 잘리던 구조를 수정했습니다.
- 메뉴 막대·Dock·컨트롤 바·카드 손잡이와 여백을 제외한 실제 공간까지 본문을 늘릴 수 있습니다. 큰 모니터에서도 1,200pt의 고정 제한을 사용하지 않습니다.
- 자동 높이 카드도 화면에 맞는 높이까지만 늘어납니다. 긴 내용은 카드 안에서 스크롤되어 하단 손잡이를 계속 사용할 수 있습니다.
- 저장한 높이는 앱을 켤 때부터 창 크기에 반영합니다. 작은 모니터로 옮겨 표시 높이가 줄어도 원래 저장된 높이는 유지합니다.

## 카드 높이와 스크롤

- 오른쪽 스크롤바를 숨겼습니다. 트랙패드와 마우스 휠로 계속 스크롤할 수 있습니다.
- 각 메모·할 일 카드 아래의 짧은 가로 손잡이를 위아래로 드래그해 카드 높이를 조절합니다. 조절한 높이는 카드별로 자동 저장됩니다.
- 손잡이를 **더블클릭**하거나 우클릭 → **내용에 맞게 자동 높이**를 선택하면 내용에 맞춰 늘어나는 원래 방식으로 돌아갑니다.
- 작게 줄인 카드의 긴 내용은 카드 안에서 스크롤됩니다. 내부 스크롤 끝에 도달하면 전체 메모 목록이 이어서 스크롤됩니다. 카드 내부에도 스크롤바를 표시하지 않습니다.
- 화면이 작은 모니터에서는 수동 높이를 화면에 맞춰 표시하며, 저장된 높이는 유지합니다. 이전 버전의 메모는 기본 자동 높이로 열립니다.

## 기본 화면

- 저장된 카드가 없으면 컨트롤 바만 표시합니다. 기본 위치는 오른쪽 위이며 직접 옮겼다면 저장한 위치를 사용합니다. 빈 상태 안내와 화면 전체를 덮던 큰 배경을 없앴습니다.
- 메모나 할 일을 추가하면 카드가 컨트롤 바 아래에 생성됩니다. 창 높이는 카드 내용에 맞춰 늘어나고 줄어들며, 모두 삭제하면 다시 컨트롤 바만 남습니다.
- 카드가 화면의 사용 가능한 높이를 넘으면 카드 영역만 스크롤됩니다. 창 위쪽 위치는 고정됩니다.
- **자동 저장** 상태와 **앱 종료** 버튼을 컨트롤 바로 옮겼습니다. 아래쪽 상태 표시줄은 제거했습니다.
- 컨트롤 바와 카드에만 배경을 표시합니다. 기존 메모는 앱을 다시 열 때 복원됩니다.

## 모니터 배치

- 상단 메뉴 막대, 노치, 하단 또는 좌우 Dock 영역을 피해 여백을 두고 배치합니다. 자동으로 숨기는 Dock에도 보수적으로 공간을 확보합니다.
- 기본 자동 배치에서는 외장 모니터가 연결되어 있으면 외장 모니터를 우선 사용합니다. 여러 대이면 현재 사용 중인 외장 모니터를 유지합니다.
- 손잡이로 직접 옮긴 뒤에는 선택한 모니터와 위치를 우선합니다. MacBook 화면에 직접 놓았다면 외장 모니터가 연결되어 있어도 그 위치를 유지합니다. 자동 배치로 돌아가려면 손잡이를 더블클릭합니다.
- 모니터 연결·해제, 잠자기 복귀, 데스크톱 전환 후 위치와 높이를 다시 계산합니다. 선택한 화면이 없으면 연결된 화면으로 옮겨 표시하며, 원래 화면이 돌아오면 그 위치를 복원합니다.

## 사용법

- 컨트롤 바 왼쪽 **점 손잡이 드래그**: 메모 전체를 이동합니다. **더블클릭**하면 기본 오른쪽 배치로 돌아갑니다.
- **메모 추가**: 새 메모가 맨 위에 생깁니다. 바로 입력하거나 기존 메모 본문을 클릭해 수정합니다.
- **할 일 추가**: 여러 항목을 담는 할 일 카드가 생깁니다.
- 할 일 입력 중 **Enter**: 현재 항목 바로 아래에 새 항목을 만듭니다.
- **Shift+Enter**: 같은 항목 안에서 줄을 바꿉니다.
- 항목 왼쪽의 **원형 버튼**: 해당 항목만 지웁니다. 마지막 항목을 완료하면 빈 입력 줄 하나가 남습니다.
- 카드 오른쪽 위 **휴지통**: 해당 카드 전체를 삭제합니다.
- 카드 아래 **가로 손잡이 드래그**: 카드 높이를 조절합니다. **더블클릭**하면 자동 높이로 되돌립니다.
- **스크롤**: 카드가 많아지거나 내용이 화면 높이를 넘으면 아래로 스크롤합니다. 컨트롤 바는 고정됩니다.
- **⌘Z / ⇧⌘Z**: 입력, 카드 삭제, 항목 완료, 높이 조절을 실행 취소하거나 다시 실행합니다.
- **⌃⌥N** 또는 메뉴 막대의 메모 아이콘: 패널을 열거나 숨깁니다. **Esc**로도 숨길 수 있습니다.
- 컨트롤 바의 **앱 종료** 버튼 또는 메뉴 막대의 메모 아이콘 우클릭 → **Wall Note 종료**로 앱을 완전히 종료합니다. 메모를 편집 중일 때는 **⌘Q**로도 종료할 수 있습니다. **Esc**는 종료가 아니라 숨기기입니다.

## 저장

입력 후 약 0.25초 뒤에 자동으로 저장합니다. 이동한 위치도 드래그를 마치면 저장합니다. 숨기거나 정상 종료할 때도 저장하며, 앱을 다시 열면 마지막 내용과 위치를 복원합니다.

저장 파일: `~/Library/Application Support/SideMemo/notes.json`

인터넷 연결은 필요하지 않습니다. 별도의 계정, 클라우드 동기화, 분석 기능이 없습니다. 저장 오류는 패널에 표시하며, 읽을 수 없는 기존 파일은 덮어쓰지 않습니다.

## 소스와 빌드

Xcode Command Line Tools가 설치된 Mac의 터미널에서 이 폴더로 이동한 뒤 실행합니다.

```sh
zsh build.sh
zsh test.sh
```

`build.sh`는 Apple Silicon용 최적화 빌드와 로컬 서명을 만듭니다. `Source`에 UI, 저장 모델, 테스트, 아이콘 생성 코드가 들어 있습니다.

## 검증 범위

컴파일, 앱 번들 서명, 저장·복원, 한국어·이모지 데이터, 500개 메모 저장, 여러 할 일의 추가·완료, 카드 삭제, 실행 취소·재실행, 저장 실패 복구 및 손상된 파일 보호를 검사했습니다. 화면 배치 계산은 MacBook 단독, 외장 모니터 연결·해제·재연결, 여러 모니터, 음수/상하 좌표, 자동 숨김과 좌우 Dock, 노치 및 작은 해상도를 대상으로 회귀 테스트합니다.

1.2에서는 빈 상태의 52pt 창, 카드 추가·삭제에 따른 높이 변경, 화면 높이 제한과 상단 위치 유지도 검사합니다.

1.3에서는 카드별 높이 저장·복원, 이전 저장 파일 호환, 자동 높이 복귀, 높이 범위와 잘못된 값 처리, 높이 조절의 실행 취소·다시 실행 및 내부/외부 스크롤 전달 조건을 검사합니다.

1.4에서는 빈 메모를 화면 높이까지 연속으로 늘리는 계산, 창과 카드의 높이 일치, 손잡이 공간 확보, 축소, 저장 후 재실행, 1,200pt를 넘는 외장 화면, 화면 전환, 여러 카드의 높이 독립성과 전체 스크롤, 긴 자동 높이 메모, 저장 오류 안내로 컨트롤 바가 커지는 경우도 검사합니다. 이 테스트는 실제 UI에서 공유하는 높이 계산과 저장·창 배치 코드를 사용합니다.

1.5에서는 수동 위치의 저장·재실행·초기화, 이전 파일 호환, 위치를 저장한 뒤 메모 수정, 모니터 식별자 변경과 재연결, 수동 모니터 선택, 화면 사이 빈 공간과 음수 좌표, 해상도 변경, 선택한 상단 위치 유지, 하단 최소 카드 공간, 이동 후 카드 크기 조절과 목록 스크롤 계산도 검사합니다.

현재 작업 환경에서는 컴퓨터 제어 권한이 없어 실제 화면의 드래그·클릭·스크롤 및 한글 입력기 조합 동작은 직접 검증하지 못했습니다. 한글 입력에는 macOS 기본 NSTextView를 사용합니다.

## 프로젝트 수정과 GitHub

- `Source/WallNote.swift`: 화면, 문구, 메뉴, 입력과 창 동작
- `Source/Models.swift`, `Source/MemoStore.swift`: 메모와 창 위치 저장
- `Source/PanelPlacement.swift`, `Source/SidebarLayout.swift`: 화면 위치와 카드 높이 계산
- `Source/Info.plist`: 앱 표시 이름과 버전

Xcode에서 Swift 파일을 열어 편집한 다음 `zsh build.sh`를 실행하면 새 앱에 반영됩니다. 현재는 빌드 스크립트 방식이며 `.xcodeproj`는 포함하지 않습니다.

GitHub 저장소: [kangkyuhyunn/wall-note](https://github.com/kangkyuhyunn/wall-note)

Git은 변경 이력을 이 Mac에 기록하고, GitHub는 그 이력을 보관하는 원격 저장소입니다. 원격 저장소 연결 후에는 다음 순서로 수정 내용을 올립니다.

```sh
git status
git add Source README.md build.sh test.sh .gitignore .gitattributes
git commit -m "Update Wall Note"
git push
```

터미널에서 처음 `git push`할 때는 GitHub 인증이 필요합니다. 브라우저 로그인과 Git 인증은 별개입니다.

개인 메모 파일(`notes.json`), 앱 실행 파일, 빌드 결과, 캐시와 인증 파일은 `.gitignore`로 제외합니다. 앱 배포 파일은 소스 이력과 별도로 관리합니다.
